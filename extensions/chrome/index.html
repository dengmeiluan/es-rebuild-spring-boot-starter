能力与边界

前端直连版做了什么、砍了什么、数据留在哪里

已落地
  • DSL / Lucene / ES-SQL 直查，结果表、JSON、CSV 导出
  • PIT 深分页（open → search_after → close）
  • 单文档 _explain 打分树；DSL 可带 profile
  • 实时集群监控：health + nodes stats 每 5s 采样，QPS/写入/Heap/CPU/分片
  • 查询历史、收藏、本地凭据；不经过任何第三方服务
  • 请求经扩展 service worker 转发，绕开页面 CORS 限制
刻意砍掉（需要后端/宿主）
  • REST 控制台已直连任意 ES API：reindex、tasks、snapshots、settings 等都可自行发起
  • 不提供额外账号/角色/页面权限；ES 侧权限与审计由集群自身承担
  • 不提供作业 SQLite/JDBC 持久化、定时调度与 52 页完整运维面
  • 宿主菜单、SSO 委托与功能包裁剪仍由 Spring Boot 宿主负责
数据与安全
  • 凭据默认只存本机 chrome.storage.local；取消勾选“记住凭据”则仅当前页面内存持有
  • 连接时只请求用户填写的 ES 地址的 host 授权；拒绝授权则不会发起请求，也不加载远程脚本
  • 浏览器直连受集群 CORS/TLS/网络策略约束；需要网关白名单时请让管理员放行扩展来源
  • 监控采样仅在本页内存，刷新即清空，避免把历史数据悄悄落盘
版本
