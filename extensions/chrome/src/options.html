Connect Chrome to SearchDeck

Point the extension at a running SearchDeck server. The console keeps its own session; this extension only stores the address.

Console endpoint —
https://
Bare hosts default to https. Loopback hosts default to http. Context paths are supported.
Advanced entry path
Default /searchdeck.html. Change only for a custom host mount.
Security model
01
No credentials stored. SearchDeck login, cookies and host tokens stay in the console’s own browser session. The extension never reads or writes them.
02
Per-origin permission. Chrome asks only for the server origin you save. Granting access enables connection checks; revoke it any time from chrome://extensions.
03
Remote UI in a frame. The extension loads the server’s own console. It does not bundle a second copy of the UI or inject scripts into pages.
