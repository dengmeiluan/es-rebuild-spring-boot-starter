# 控制台设计语言与交互宪法

内置运维控制台是本 starter 的一等公民。它的设计不是"能看就行"，而是一套明确的、
可测试的交互宪法——每个组件交付前逐条自检，不过关即返工。

## 设计基调

- **utilitarian 工具气质**：与 Kibana Dev Console 同语言——扁平、克制、信息密度优先、
  留白有节奏。面向每天长时间高频操作的运维/研发，效率与肌肉记忆优先于装饰。
- **扁平化**：层层嵌套容器、卡中卡、多余边框一律根治；语义边框（错误红框等）保留。
- **间距与字号只用阶梯**：间距走 `--sp` token 阶梯，标题两档制（区块头/卡头），
  禁止私造第五种间距或字号。
- **深浅双主题**：全部颜色走 CSS token，语义色（错误/警告/成功）双主题各自调准对比度。

## 交互铁律

1. **最短路径**：高频动作 ≤1 次点击直达且驻留光标常驻区；低频动作收进 ⋯ 菜单，
   禁止在高频区平铺占位。
2. **位置恒定**：同一动作的按钮在任何状态转换（展开/收起/放大/翻页/刷新/切 tab）后
   仍在同一像素位置——肌肉记忆可达。
3. **状态不重置**：翻页/刷新/切模式后，筛选条件、滚动位置、输入草稿、焦点位置全部保留。
4. **多按钮合一**：同一对象的一组互斥/成对动作合并为一个控件（双态同钮/分段控件/
   下拉聚合），禁止并排枚举两颗钮。工具行默认可见按钮 ≤5 个。
5. **弹层四要素**：真实浮层感 = 白底 + 边框 + 阴影 + 圆角，禁止透明壳平铺在表格上。
6. **键盘可达**：role+tabindex+Enter/Space 双通道；弹层 Esc 关闭且焦点回触发器。
7. **七能力标配**：可调节·可折叠·可伸缩·可展开·可收起·可检索·可定位，是每个
   工作台的交付面，状态全部落盘、重进页面还原。
8. **零自激励**：严禁事件自激励环（页面闪烁/高度正反馈/滚动条循环扩大）；
   编辑器与容器的高度链必须是确定解。

## 五条交付序列（真机全绿才算交付）

1. 展开 → 输入 → 收起 → 再展开（内容保留）
2. 放大 → 操作 → 还原（无控件被盖死）
3. 翻页 → 改每页条数 → 筛选（以新档重查不停旧页）
4. 切展示模式 A → B → A（主体不空白）
5. 开弹层 → Esc → 焦点回触发器

## 右键菜单覆盖面

右键是表格/工作台的高频第二通道，和工具行按钮共用同一动作内核与权限门。交互统一为
`CellContextMenu`（定位碰撞、二级菜单、Esc/←/→、弹层内 z-index 跟随）；宿主只构造
`CcmItem[]`，不在组件内部复制菜单壳。

| 触发面 | 入口 | 代表性动作 | 权限/副作用 |
|---|---|---|---|
| 查询模式切换条 | 右键 / ContextMenu / Shift+F10 | 切换模式、复制模式深链、默认进入模式、权限摘要、跨模式历史 | 只读；标题显示 env/角色/读写档；摘要复制目标/env/角色/查询读写 |
| 当前索引 chip | 右键 / ContextMenu / Shift+F10 | 复制索引名/深链、复制查询权限摘要、去索引工作区、清除本地选择 | 只读；标题显示读写档；摘要含目标/env/角色/查询读写与 index；清除只动本地选择 |
| 字段/值候选列表（FieldPicker / 构建器 FieldSelect / MultiFieldPicker / LuceneInput） | 右键 / ContextMenu / Shift+F10 | 选用字段（容器字段=展开子字段）、勾选/取消勾选、填入候选、复制字段名/候选文本 | 只读/本地；不触发服务端写 |
| 结果表工具行 | 右键 | 导出、行高、快照、列选、视图开关 | 只读/本地偏好 |
| 结果表列头 | 右键 / ContextMenu / Shift+F10 | 排序、筛选、复制列、列宽、冻结、列管理 | 只读/本地偏好 |
| 结果表单元格 | 右键 | 复制值/行/列、单元格详情、行展开、筛选、生成 DSL、行详情 | 只读；生成查询只复制文本 |
| 结果表行尾「更多」/行菜单 | 点击/右键 | 查看/展开/复制行 JSON、解释得分、编辑/删除文档 | 编辑仅 `editable && canWrite`；删除仅 `canOps`；受 env 页面模板封顶 |
| Lucene/沙盒命中行 | 右键 | 复制 `_id`/文档/转 DSL | 只读 |
| 查询历史行 | 右键 | 回放、收藏、复制、删除本地历史 | 本地状态；不触发服务端写 |
| 构建器条件/聚合节点 | 右键 | 复制/删除/包裹/启用切换 | 只改当前 DSL 草稿；由构建器提交时统一走查询门 |
| Boost 调参字段行 | 右键 / ContextMenu / Shift+F10 | 复制字段名、停用/启用、删除字段 | 只改本地调参草稿；执行仍走查询门 |
| 工作台配置行 | 右键 / ContextMenu / Shift+F10 | 显示/隐藏、列宽（1/2/3 列）、上移/下移 | 只改本地布局并落盘 |

规则：**菜单不自行判断权限**；宿主只把当前身份允许的动作放进 items（隐藏而不是仅置灰），
服务端仍按页面读/写键与连接 env 模板二次裁决。PROD/QA/STAGING 只改变可用动作与顶部环境
标识，不改变同一动作的语义。新增右键面必须同时补：键盘入口（并在快捷键速查面板登记）、
动作权限来源、以及一条行为 spec。菜单打开后焦点进入首项，↑/↓ 循环选择，Esc 关闭。
层序走 `--z-ctx-top` 顶档，必须高于 Picker 浮岛与全屏面（字段候选内右键曾被浮岛盖住）。

其余列表页（安全中心用户表、系统设置、命中矩阵、Boost 对比结果等）复用 QRT/RT，继承同一
套单元格/列头/工具行右键内核；不再为单个视图复制菜单壳。

## 测试即契约

- 前端约 12000 个用例中，相当一部分是**源码契约锁**（读源码断言设计形态）与
  **真机行为链**（CDP 驱动真实浏览器点按）。重构想"顺手改个样式"时，
  红了的锁就是在提醒：这次改动动了设计语言，请有意识地随迁，而不是绕过。
